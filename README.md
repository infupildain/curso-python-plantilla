# Curso Python 2026-27 — repositorio del alumno

Este es **tu** repositorio del curso. Aquí tienes los apuntes, los enunciados y las plantillas
de los ejercicios. Cada vez que haces *push*, GitHub comprueba automáticamente tu código.

## Primeros pasos en PyCharm

1. *File → New Project from Version Control…* (o *Get from VCS*) y pega la URL de este repositorio.
2. Acepta crear un entorno virtual e instalar `requirements.txt` (si no lo ofrece, en la terminal:
   `pip install -r requirements.txt`).
3. *Settings → Tools → Python Integrated Tools → Default test runner: pytest*.

## Cómo trabajar un ejercicio

1. Lee el `enunciado.md` de la carpeta del ejercicio.
2. Programa en el archivo `.py` que se indica y ejecútalo con ▶.
3. Comprueba tu solución: clic derecho en el archivo `test_*.py` → *Run 'pytest in …'*.
4. Entrega: *Git → Commit…* (Ctrl+K) → **Commit and Push**.
5. En GitHub, pestaña **Actions**: ✅ verde = superas las comprobaciones automáticas.
   Lo que no se puede comprobar automáticamente (diagramas, pruebas, reflexión, estilo) lo corrige el profesor.
